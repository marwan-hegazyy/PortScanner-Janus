# Port Scanner 🚀

سكربت بلغة **Python** لفحص النوافذ (Ports) على عنوان IP محدد للتحقق من الأبواب المفتوحة والخدمات النشطة.

---

## 🛠️ المميزات
* فحص النوافذ من **1 إلى 1024** (أو النطاق المخصص).
* إخراج النتائج في التيرمينال بلون أوضح للنوافذ المفتوحة.
* يعتمد على مكتبة `socket` المدمجة في بايثون.

---

## 💻 المتطلبات
* **Python 3.x**
* نظام تشغيل **Linux** (مثل Kali Linux) أو **Windows** / **macOS**.
